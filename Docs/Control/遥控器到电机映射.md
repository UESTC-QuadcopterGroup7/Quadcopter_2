# 遥控器到电机映射

实现入口：[RC_Config.h](../../MyLib/RC_Config.h)、[RC_Control.c](../../MyLib/RC_Control.c)、[Receive_IC.c](../../MyLib/Receive_IC.c) 和 [main.c](../../Src/main.c)。新文件已加入 `LED.uvprojx`。

当前已接入**遥控输入归一化、目标姿态生成、GY86 姿态/角速度闭环和 X 架电机混控**。横滚、俯仰采用角度 P 外环与角速度 PID 内环，偏航采用角速度 PID；实现、参数和整定步骤见 [PID 姿态闭环控制与调参](PID姿态闭环控制与调参.md)。默认增益尚未针对实机整定，应先拆桨核对方向。

## 1. 机头、槽位和电机编号

以 GY86 的 +X 正方向为机头，从飞机上方向下看：

```text
                     机头 / GY86 +X
                           ↑
            左前 M3                 右前 M2
              CW                     CCW

            左后 M4                 右后 M1
              CCW                     CW
```

| PCB 槽位，从左到右 | 机体位置 | 程序电机编号 | PWM 引脚 | 混控要求的俯视旋向 |
| --- | --- | --- | --- | --- |
| 最左 | 左后（左下） | M4 | PB1 / TIM3_CH4 | CCW，待实测核对 |
| 左二 | 左前（左上） | M3 | PB0 / TIM3_CH3 | CW，已确认 |
| 左三 | 右前（右上） | M2 | PA7 / TIM3_CH2 | CCW，待实测核对 |
| 最右 | 右后（右下） | M1 | PA6 / TIM3_CH1 | CW，待实测核对 |

槽位观察方向见 [PCB 接口文档](../../PCB/电机接口引脚说明.md)。CW/CCW 都指俯视时的实际旋转方向。软件只能改变油门，不能通过 PWM 大小改变电机旋向。偏航混控要求对角同向、相邻反向。

`motor_us[0..3]` 按 **M1、M2、M3、M4** 存放，调用 `BLDC_SetThrottle_us()` 时下标加 1；不是按槽位从左到右存放。

## 2. 四个遥控通道

输入脉宽为 1000～2000 μs，自动回中为 1500 μs。默认分配如下：

| 接收机通道 | 输入引脚 | 功能 | 默认脉宽增大时的动作 | 目标量范围 |
| --- | --- | --- | --- | --- |
| CH1 | PA0 | 横滚 | 右滚 | -20°～+20° |
| CH2 | PA1 | 俯仰 | 低头、向前倾 | -20°～+20°，抬头为正 |
| CH3 | PB10 | 油门 | 中点以上增加油门 | 0～1 |
| CH4 | PB7 | 偏航 | 右转 | -90°/s～+90°/s |

横滚、俯仰、偏航在 **1480～1520 μs** 内输出 0，死区外连续映射到 -1～+1。CH2 默认反向，使前推且脉宽增大时得到负俯仰目标。必须用实际遥控器核对哪一方向使脉宽增大；如不符，只调整 `RC_Config.h` 中对应的 `RC_*_DIRECTION`，取 `1` 或 `-1`。

通道可通过 `RC_*_CHANNEL` 重排，数值是从 0 开始的数组下标。`RC_MakeSetpoint()` 将归一化输入转换成 `roll_deg`、`pitch_deg`、`yaw_rate_dps`。偏航采用角速度目标，松杆为 0°/s，不是要求机头回到 0° 航向。

### 自动回中油门

CH3 按单向油门设计，回中即停止：

| CH3 脉宽 | 归一化油门 | 混控前基础输出 |
| --- | --- | --- |
| 1000～1520 μs | 0 | 1000 μs，停止值 |
| 1760 μs | 0.5 | 1500 μs |
| 2000 μs | 1 | 2000 μs |

```text
throttle = clamp((CH3 - 1520) / 480, 0, 1)
T = 1000 + throttle * 1000
```

如果设置 `RC_THROTTLE_DIRECTION=-1`，先将脉宽反向，再执行相同的计算。**松开油门会停机**，这套交互不能在油门摇杆回中后自动保持悬停。

## 3. X 型混控

与现有姿态代码一致：R 右滚为正、P 抬头为正、Y 右转为正。以下 T/R/P/Y 均以 μs 表示，Y 对应左前 CW 的旋向配置：

```text
M1（右后） = T - R - P - Y
M2（右前） = T - R + P + Y
M3（左前） = T + R + P - Y
M4（左后） = T + R - P + Y
```

| 控制动作 | 增加输出的电机 | 减少输出的电机 |
| --- | --- | --- |
| 右滚 | 左前 M3、左后 M4 | 右前 M2、右后 M1 |
| 抬头 | 左前 M3、右前 M2 | 左后 M4、右后 M1 |
| 右转 | 右前 M2、左后 M4（CCW） | 左前 M3、右后 M1（CW） |

R/P/Y 现在由 PID 输出，初始限幅分别为 ±200、±200、±120 μs。输出超出 1000～2000 μs 时，先按同一比例缩小超出可用跨度的差速，再整体平移公共油门，保持各轴差速比例；因此饱和时平均输出可能偏离基础油门。

`RC_Control_Update()` 负责目标与解锁状态，单独调用时电机保持停止值。`FC_Control_Update()` 在检查传感器反馈后运行 PID，再调用 `RC_Mix()`；解锁、回中停机和超时保护均已保留。

## 4. 启动、解锁和停机

1. **拆除全部螺旋桨**。上电后四路维持 1000 μs，等待原有的 5 秒电调初始化和随后约 1 秒陀螺偏置校准结束。
2. 机体接近水平且姿态有效，油门回中、横滚和俯仰居中，偏航向右打满并保持 1 秒，`s_flight_control.rc.armed` 变为 1。
3. 先松开偏航，再将 CH3 推过中点死区；四台电机开始获得油门，CH1/CH2/CH4 控制差速。
4. CH3 松杆回中，四路立即改为停止值，与其他摇杆的位置无关。
5. 油门回中，偏航向左打满并保持 1 秒，重新上锁。

任一通道尚未收到合法脉冲、脉宽异常或超过 **100 ms** 未更新，控制任务会输出停止值并上锁。恢复信号后必须重新执行解锁手势，高油门不会自动重启。这里检测的是 **PWM 输入停止或异常**；接收机若在无线失联后继续输出旧的有效脉宽，飞控无法仅凭该信号识别无线失联，应将接收机失控输出设置为 CH3 回中。

控制任务每 5 ms 处理一次，TIM3 电调输出仍为原来的 50 Hz；停止脉宽在后续 PWM 周期生效。加速度校准模式 `ACCEL_CAL_MODE=1` 不启动电机输出及控制任务。
PID 闭环还检查反馈有效性、30 ms 反馈超时、实际采样间隔及总倾角限制。总倾角达到 70° 即停机并锁存故障；扶正至 15° 内、油门回中及横滚/俯仰居中、偏航左满保持 1 秒才解除，随后仍须重新解锁。具体条件见 [闭环保护说明](PID姿态闭环控制与调参.md#5-时间反馈和保护)。

## 5. 拆桨检查与测试

调试器可查看：`PWM_IN_Wid[0..3]`、`s_flight_control.rc.signal_valid`、`s_flight_control.rc.armed`、`s_flight_control.rc.command`、`s_flight_control.rc.setpoint`、`s_flight_control.rc.motor_us[0..3]`，以及 `s_flight_control.status`、`s_flight_control.rate_pid[0..2]`。

先核对四个槽位和电机旋向，再核对各摇杆对应的通道与增减方向。用适中的油门观察上述三种差速动作；回中油门确认四路全部返回 1000 μs，再验证接收机断信号后的停机行为。
