# 电调 PWM 信号

## 周期、脉宽与占空比

项目使用类似舵机的 PWM 脉冲控制电调。电调通过每个周期内的**高电平脉宽**识别油门，而不是通过整个周期的长度识别油门。

| 参数 | 含义 | 项目配置 |
| --- | --- | --- |
| 周期 | 相邻脉冲的重复间隔 | 20 ms，即 50 Hz |
| 脉宽 | 每个周期内高电平的持续时间 | 1000～2000 μs |
| 占空比 | 高电平脉宽占周期的比例 | 5%～10% |

例如，脉宽为 2000 μs、周期为 20000 μs 时，占空比为 `2000 / 20000 = 10%`。在当前代码的约定中，1000 μs 是最小油门，2000 μs 是最大油门；电调实际支持的范围以其说明书和校准结果为准。

**20 ms 是周期，不是满油门脉宽。**若高电平持续整个 20 ms 周期，信号将接近持续高电平，不符合这里使用的 1～2 ms 脉冲格式；电调对无效信号的处理取决于具体型号。

## 定时器配置

`MyLib/BLDC.c` 使用 TIM3 产生四路 PWM：

```c
TIM_Base_CFG(TIM3, 84 - 1, 20000 - 1,
             TIM_CLOCKDIVISION_DIV1, TIM_COUNTERMODE_UP);
```

当 TIM3 输入时钟为 84 MHz 时：

- `PSC = 83`：定时器计数频率为 84 MHz / 84 = 1 MHz，每计数一次为 1 μs。
- `ARR = 19999`：周期为 20000 次计数，即 20 ms。
- `CCR`：PWM1、高电平有效配置下，数值对应高电平脉宽，单位为 μs。

| CCR | 脉宽 | 占空比 | 项目约定 |
| --- | --- | --- | --- |
| 1000 | 1 ms | 5% | 最小油门 |
| 1500 | 1.5 ms | 7.5% | 中间控制量 |
| 2000 | 2 ms | 10% | 最大油门 |

## 代码接口

`MyLib/BLDC.h` 定义 `BLDC_MIN_US = 1000`、`BLDC_MAX_US = 2000`，以及 `BLDC_OFF_US = BLDC_MIN_US`。停止值仍是持续发送的最小脉宽，并不是关闭 PWM 或断开电源。

`BLDC_SetThrottle_us(pulse_us, idx)` 将脉宽限制在 1000～2000 μs，再写入对应通道：

| `idx` | 定时器通道 | 引脚 |
| --- | --- | --- |
| 1 | TIM3_CH1 | PA6 |
| 2 | TIM3_CH2 | PA7 |
| 3 | TIM3_CH3 | PB0 |
| 4 | TIM3_CH4 | PB1 |

电机测试、解锁或电调校准前，必须拆除全部螺旋桨。最小脉宽不保证所有型号的电机一定停止，具体行为以电调说明书为准。

## 其他协议

Oneshot125、Multishot 和 DShot 使用不同的时间参数或编码方式，不能直接套用上述 50 Hz、1～2 ms 设置；使用前需确认电调支持并调整驱动。
