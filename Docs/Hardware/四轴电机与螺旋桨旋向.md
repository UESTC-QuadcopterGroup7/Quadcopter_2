# 四轴电机与螺旋桨旋向

这份文档介绍如何区分电机和螺旋桨的旋转方向，以及四轴上如何匹配。

> **安全第一：任何电机转向检查、接线调整和电调校准前，必须拆掉全部螺旋桨。接线调整前断开电调动力电源，确认电机完全停止。**

## 1. 先统一观察方向

本文中的顺时针、逆时针都以**从飞机上方向下看电机和螺旋桨**为准：

| 缩写 | 英文 | 俯视看到的旋转方向 |
| --- | --- | --- |
| CW | Clockwise | 顺时针，和钟表指针方向相同 |
| CCW | Counterclockwise | 逆时针，和钟表指针方向相反 |

从下方看同一个正在转动的电机，看到的顺逆时针会相反。因此和别人对照时，要先确认观察方向。

### “正”和“反”到底是什么？

在常见的航模螺旋桨叫法中，**正桨通常指俯视 CCW，反桨通常指俯视 CW**。例如有些桨的普通型号是正桨，带 `R` 或 `P` 后缀的是反桨。

但不同厂家对 `R`、`P`、正反及“推桨”的标法可能不同，电机销售页面中的“正转电机”也可能是在描述螺纹而非实际旋向。**确定型号时优先看厂家对 CW/CCW 和观察方向的明确说明，不要只看“正”“反”两个字。**

## 2. 银色和黑色电机，哪个正转？

目前工程中没有记录这两种电机的品牌、型号或厂家颜色定义，**不能仅凭“银色”或“黑色”可靠判断哪个是 CW、哪个是 CCW**。如果你说的是电机顶部的银色、黑色螺母，颜色通常用于区分配套型号或螺纹，但各厂家并不统一；如果是电机外壳的颜色，也不能据此判断旋向。

例如，某些商家会将黑色螺母型号称为 CW，但这不是所有电机都遵循的规则。要确定你手中这一套：

1. 查看电机本体、包装或购买页面，记录完整型号，以及 `CW`、`CCW`、箭头和螺纹说明。
2. 在**拆掉全部螺旋桨**后，按照电调说明单独低速检查每个电机，从飞机上方向下观察真实旋转方向。
3. 将实测结果记录下来：哪一个银色型号是 CW、哪一个黑色型号是 CCW，再与对应位置和桨叶匹配。

同型号三相无刷电机在合适的电调驱动下通常可双向旋转，因此“外壳颜色”并不会物理上决定它只能朝一个方向旋转。

### 别把螺纹方向当成旋转方向

- **电机旋转方向**：通电后电机转子转动的方向。
- **螺纹方向**：螺母拧紧时绕轴转动的方向，取决于是正牙还是反牙。
- **螺旋桨方向**：桨叶设计工作时的旋转方向。

三者相关，但不是同一回事。螺母颜色、正牙/反牙和 CW/CCW 的对应关系应查具体型号；不要为了让颜色“匹配”而硬拧螺母，也不要假定所有电机都靠反牙自锁。确认厂家的固定方式、配套螺母和拧紧要求。

## 3. 哪个螺旋桨是正桨、哪个是反桨？

最可靠的方法是**查桨上的完整型号及厂家说明**，而不是只看颜色：

| 厂家明确标记 | 俯视工作方向 | 常见叫法 |
| --- | --- | --- |
| `CCW` | 逆时针 | 通常称正桨 |
| `CW` | 顺时针 | 通常称反桨 |

有些桨只在其中一种上标注 `R`、`P`，另一种没有方向字母；数字一般用于表示桨的规格，不能单独证明旋向。不同品牌的后缀定义可能不同，必须核对该型号的说明。

一对 CW 和 CCW 螺旋桨的叶片形状通常互为镜像。若没有明确标记，可对照厂家图片或拿已知方向的同型号桨比较；**无法确认时不要装机试飞**。桨叶上的字朝哪一面也应以厂家安装说明为准，不能单独作为判断旋向的依据。

目标是：桨按设计方向旋转时，将空气向下推，使飞机获得向上的推力。桨叶方向不匹配会大幅降低推力，严重时飞机无法正常起飞或发生翻覆。

## 4. 电机和桨怎么配？

先确定飞控要求的位置旋向，再匹配同方向的桨：

| 俯视实测电机方向 | 配套桨 |
| --- | --- |
| CW，顺时针 | 厂家规定工作方向为 CW 的桨 |
| CCW，逆时针 | 厂家规定工作方向为 CCW 的桨 |

四轴一般有两个 CW、两个 CCW，**对角两个方向相同，相邻两个方向相反**。这样可以让各电机的反作用扭矩相互平衡。

例如，下面是一种常见的 X 架布局，机头向前：

| 机体位置 | 示例旋向 | 示例配桨 |
| --- | --- | --- |
| 左前 | CW | CW 桨 |
| 右前 | CCW | CCW 桨 |
| 左后 | CCW | CCW 桨 |
| 右后 | CW | CW 桨 |

**这只是示例，不是本项目已确认的电机布局。** 四轴也可以将四个方向全部反过来；必须与实际飞控的电机编号、旋向及混控配置一致，否则可能失控或翻机。

## 6. 安全检查顺序

1. **拆掉全部螺旋桨**，断开电调动力电源。核对电机、电调、螺母和桨型号与厂家说明。
2. 先确认飞控混控规定的每个机臂的电机编号和目标旋向。不要直接照搬上面的示例。
3. 确保飞机固定、电机及电线远离手和杂物，按照电调说明接通电源，逐个低速检查电机；从上方向下观察并记录实际方向。
4. 如方向不符，先断开电调动力电源、等待电机停转；再按照具体电调说明设置转向，或在断电条件下交换该电机三根相线中的任意两根。**只交换电调到电机的三相线，不是电池正负线，也不是 PWM 信号线。** 完成后仍须拆桨重新确认。
5. 全部方向和通道核对无误后，断电，根据厂家说明安装对应 CW/CCW 桨及配套紧固件。不要在方向或固定方式不明时试飞。
