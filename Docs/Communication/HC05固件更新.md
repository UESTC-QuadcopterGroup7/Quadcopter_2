# 通过 HC‑05 更新飞控固件

Windows 工具通过 HC‑05 的蓝牙串口更新 STM32F401RE。首次用 SWD 安装引导程序，之后应用固件通过蓝牙更新。Keil 的 `Sample` 仍可用于原有的有线下载。要保留蓝牙更新能力，使用下面的 `BluetoothApp` 构建和上传流程。

## 1. 接线与供电

断开电调动力，单独给飞控和 HC‑05 供电。HC‑05 保持数据模式，模块与 STM32 之间的串口为 **115200、8N1**。

| 飞控 USART1 | HC‑05 |
| --- | --- |
| PA9 / TX | RXD |
| PA10 / RX | TXD |
| GND | GND |

观察遥测只用到 PA9 发送。蓝牙更新需要 PA10 接收，所以请确认 [两根串口信号线](../../Firmware/Drivers/UART_Set.h) 都已接好。供电电压按实际 HC‑05 转接板标注连接。

## 2. 首次安装

1. 从项目根目录运行构建脚本。默认使用 `C:\Keil_v5` 的 ARM Compiler 5，路径不同时可加 `-KeilRoot`。

   ```powershell
   powershell -NoProfile -ExecutionPolicy Bypass -File .\Tools\Bluetooth\Build-Bluetooth.ps1
   ```

   构建生成 `BluetoothBootloader.uvprojx`、`BluetoothApp.uvprojx`、引导程序 HEX 和应用 BIN。第一次构建还会生成本机设备密钥 `Firmware/Bootloader/BootKey.local.h`。私下备份这份文件，后续上传需要用和板上引导程序一致的密钥。

2. 用 Keil 打开生成的 `BluetoothBootloader.uvprojx`，选择 `BluetoothBootloader` 目标。接上 J-Link 或 ST-Link，在下载设置中选择当前探针和 SWD，擦除方式选 **Erase Sectors**，点 **Download**。引导程序的 HEX 为 `Objects\BluetoothBootloader\Bootloader.hex`，也可用现有 SWD 烧录工具写入。初次安装会替换 Flash 起始扇区的原有启动代码。
3. 运行或复位飞控。没有有效应用时，飞控会留在引导程序中等待第一份蓝牙应用固件。结束 SWD 调试会话后执行下一节的上传命令。

## 3. 每次更新应用

保持电调动力断开。先关闭匿名上位机的串口连接，让上传工具独占 HC‑05 的出站串口。本机实测使用 `COM9`；换电脑或重新配对后，用 Windows 蓝牙设置确认端口，也可用 `Update-Firmware.ps1 -ListPorts` 列出可见端口。

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\Tools\Bluetooth\Build-Bluetooth.ps1 -Component App
powershell -NoProfile -ExecutionPolicy Bypass -File .\Tools\Bluetooth\Update-Firmware.ps1 -Port COM9
```

- 上传默认读取 `Objects\BluetoothApp\FlightController.bin`。也可用 `-Firmware` 指定先前生成的 BluetoothApp BIN。
- 当前停电机遥测固件会收到更新请求并自动复位进入引导程序。若运行的是启用电机输出的 BluetoothApp，先启动上传命令，看到 `Waiting for the bootloader` 后按下飞控复位键。引导程序每次启动都会短暂侦听更新请求。
- 工具显示 `Application installed and verified` 时，飞控已校验应用区，随后自动重启。把机架放平等零偏校准，再打开匿名上位机选 **COM9、115200** 看姿态。
- 可在初装后使用上传命令加 `-Probe` 核对引导程序版本与容量。该命令会请求进入引导程序但不擦写；如果已有有效应用，空闲约 25 秒后会回到应用。

## 4. 中断恢复

上传先擦写暂存区，整包通过 CRC32、HMAC-SHA256 和向量表检查后才写应用区。上传阶段断链时重新运行上传命令即可。有有效旧应用时，空闲超时或复位后仍可启动旧应用。完整暂存包确认后如果在安装阶段断电，重新上电会从暂存包继续安装。

| 内容 | STM32F401RE Flash |
| --- | --- |
| 引导程序 | 扇区 0，`0x08000000–0x08003FFF` |
| 当前应用与校验信息 | 扇区 1–5，`0x08004000–0x0803FFFF` |
| 暂存镜像与校验信息 | 扇区 6–7，`0x08040000–0x0807FFFF` |

布局参考 [STM32F401 参考手册 RM0368](https://www.st.com/resource/en/reference_manual/dm00096844-stm32f401xbc-and-stm32f401xe-advanced-armbased-32bit-mcus-stmicroelectronics.pdf)。蓝牙工具的更新范围是应用固件，引导程序升级走 SWD。
